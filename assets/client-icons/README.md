# Client SVG icon sources / attribution

Icons stored here are rasterized at 11 × 11 pixels by GTK at runtime. Vector
geometry remains faithful to the online originals; a neutral monochrome fill
was added for visibility on dark GTK themes. No network access is required.

- `browser.svg`: Material Design Icons `web` (Pictogrammers), Apache-2.0,
  https://github.com/Templarian/MaterialDesign/blob/master/svg/web.svg
- `gamepad.svg`: Material Design Icons `gamepad-variant`, Apache-2.0,
  https://github.com/Templarian/MaterialDesign/blob/master/svg/gamepad-variant.svg
- `wiiu.svg`: Material Design Icons `nintendo-wiiu`, Apache-2.0,
  https://github.com/Templarian/MaterialDesign/blob/master/svg/nintendo-wiiu.svg
- `switch.svg`: CoreUI Icons Free `cib-nintendo-switch`, CC BY 4.0,
  https://github.com/coreui/coreui-icons/blob/main/svg/brand/cib-nintendo-switch.svg
- `android.svg`: CoreUI Icons Free `cib-android`, CC BY 4.0,
  https://github.com/coreui/coreui-icons/blob/main/svg/brand/cib-android.svg
- `3ds.svg`: CoreUI Icons Free `cib-nintendo-3ds`, CC BY 4.0,
  https://github.com/coreui/coreui-icons/blob/main/svg/brand/cib-nintendo-3ds.svg
